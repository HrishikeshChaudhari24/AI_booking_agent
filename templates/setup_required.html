Google OAuth Setup Required

Missing Configuration

Google OAuth credentials are not configured. To use the AI Booking Agent with Google Calendar, you need to set up OAuth credentials.

Quick Setup Steps:
  1. Get OAuth Credentials:
    • Go to Google Cloud Console
    • Create/select a project and enable Google Calendar API
    • Create OAuth 2.0 Client credentials
    • Download the credentials.json file
  2. Add Redirect URI:
    Add this redirect URI to your Google OAuth configuration:
    {{ request.url_root }}auth/callback
  3. Configure Credentials:

    Add these values to your Replit Secrets:

    • GOOGLE_CLIENT_ID
    • GOOGLE_CLIENT_SECRET
Upload credentials.json
